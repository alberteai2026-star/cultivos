# Documentación del proyecto

Estructura inicial de documentación:

- `docs/arquitectura/`: decisiones técnicas, diagramas y ADRs.
- `docs/modulos/`: especificación funcional por módulo (M1...M32).
- `docs/api/`: contratos API, ejemplos y guías de integración.
- `docs/ESTADO_IMPLEMENTACION.md`: snapshot de avance y brechas pendientes hacia producción.
- `docs/FRONTEND_READINESS.md`: checklist concreto para iniciar frontend (bloqueadores, orden sugerido y Go/No-Go).
